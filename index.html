AgentID Daily

Check in once a day. Build your streak. Tip any Agent ID by name.
Built natively on Binance Agent ID (.ai) — BNB Chain.

1 · Connect your wallet

Use Binance Wallet, MetaMask, or any EVM wallet on BNB Chain. Only Agent ID holders can check in or receive tips.

2 · Daily check-in

One free check-in per UTC day (you only pay gas). Miss a day and your streak resets to 1. Your check-in is an on-chain proof that your Agent ID is active.

3 · Tip an Agent ID by name

Type an Agent ID name (for example rynald.ai). We resolve it on-chain to its owner — you never paste a wallet address. Tips go straight to the agent; this contract never holds funds. Tips are irreversible, so double-check the name.

About & safety

Contract: 0x488322F4a8Dbb08b6C1f822afB247577b6862f46 (BNB Chain). Source verified and open-source on BscScan. Agent ID contract: 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F.

No QR-code login, no sessions stored on any server, no action is ever taken on your behalf — every transaction is signed by you in your own wallet. The contract owner can only pause check-ins in an emergency and can never move, mint, freeze, or withdraw user funds. This project promises no returns or income of any kind.
